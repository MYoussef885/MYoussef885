## 👋 About me

I'm an **AI Engineer** working at **Aurevon Group** and **Talk4Impact**. Outside of work I build personal side projects, mostly with **Claude Code** and **Vercel v0**, turning ideas into working products as fast as I can.

I started out with hands-on machine learning (prediction models, computer vision, deep learning) and my most-starred work on this profile comes from that era. These days I focus on building AI products end to end.

- 🔭 Building: AI-powered side projects with Claude Code and v0
- 🌱 Always exploring: agents, LLM tooling, applied ML
- 💬 Ask me about: machine learning, computer vision, AI engineering
